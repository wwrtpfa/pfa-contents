# 制作案例

以下案例展示不同输入条件下的制作方法，不作为固定画幅、时长或布局模板。

## 案例一：已有录屏，保留原声并加入动效

`Built-in Retina Display.mp4` 是一段带人声的 WorkBuddy 屏幕录制。它需要展示原有 UI、人物画中画，以及 AI 重做网站和生成应用的过程。

1. 检查原片：`3456×2160 / 60 fps`，约 `56.4 s`，自带可用讲话声。因此保留原声，没有调用 TTS。
2. 校对中英字幕与技术名词。结合语音活动、词级时间戳和画面，把明显气口、等待和卡顿写成可检查的剪辑计划；约去掉 `9.6 s`。音视频和字幕共同映射到剪后时间。
3. 用户的参考图要求黄色双语字幕、原画面下部位置、无黑色底板。先出截图确认，再渲染全片。
4. 为了不遮录屏顶部内容，画布在源画面上方外扩 `112 px`，输出 `3456×2272`。细进度线位于外扩顶栏，章节信息也留在原视频之外。
5. 根据“需求 → 原型 → 应用”的讲述，用 Remotion 做对应的阶段动效。这个例子适合放进外扩顶栏，但以后应先看画面留白；局部指示、对比和说明镜头也可以在画面其他位置出现。
6. 成片约 `46.8 s`，H.264 + AAC；完整解码和代表帧检查通过。发布后在内容管理确认状态为“已发布”，不能仅凭上传完成提示认定发布成功。

本次返工的原因是初版进度条和黑色字幕底板覆盖了原录屏，且初版没有真正加入内容动效。以后在整片渲染前，应先把进度条、字幕和动效同时放进代表帧核对。

## 案例二：程序员如何练英语口语

本案例展示一种可复用方法，不规定所有视频都必须 75 秒或用同一模型。

1. 从“我想学 AI 做科普视频”出发，先调研 MoneyPrinterTurbo、OpenCut、OpenMontage、pyVideoTrans、VideoCaptioner、video-shotcraft、FunClip 等工具，区分自动生成、剪辑、字幕和 Agent 流水线。
2. 比较三种制作方式：代码渲染、原生视频模型生成镜头、大模型加真实素材的混合制作。教学文字较多，因此选代码渲染。
3. 聚焦为“程序员如何练英语口语”，整理高频场景、每天 10 分钟动作和七天练习安排，写出七镜逐字旁白与分镜。
4. 获得用户确认后，用其本人授权录音及配套逐字稿，通过本机 MLX Qwen3-TTS 逐镜合成七段旁白。实测旁白总计约 65.6 秒；各镜留自然停顿，视频总长约 75 秒。
5. 用 Remotion 制作 1080×1920、30 fps 的七镜竖屏动画，合成旁白与中文字幕；抽取关键帧发现第六镜日程卡片与底部字幕重叠，改为两列布局。
6. 导出 H.264/AAC MP4，使用 `ffprobe` 核对画幅、帧率、时长和音轨，用 `ffmpeg` 完整解码并检查音量；另打包可编辑工程。

这条视频的画面由代码与文字动效生成，并非视频生成模型直接输出连续实拍画面。参考录音只用于本地合成，没有放入交付工程。

## 案例三：为什么你的 AI 视频像 PPT（84 秒，9 镜，Remotion）

这个案例的重点不是工具，而是**先有分镜、再动画面**。

1. 先有策划稿 `preproduction-plan-v2.md`：一条视频只讲一个结果（"用 3 个剪映动作把 AI 视频做成视频"），9 镜各自写明目的、逐字旁白、画面、屏幕文字和时长。钩子、标题、封面、字幕、转场、关键帧、MG、弹窗、画中画这些元素，全部在分镜里就标好了"在哪出现、显示多久、和第几句对齐"，渲染时不再做设计决策。
2. 旁白按 9 段用百炼自定义音色（`qwen-audio-3.1-tts-flash`）远程合成，实测总计约 80.7 秒；加 0.34 秒镜间隙和 1 秒片尾，成片 84.38 秒、2531 帧。
3. `build_timeline.py` 做首尾静音裁剪 + `loudnorm -16`，把每段时长、镜内字幕、模块名、`0x / 03` 步骤写进 `timeline.json`，同时导出独立双语 SRT。
4. Remotion 按场景一文件实现，每镜自带 `<Audio>`，字幕与顶部进度条挂在最外层按全局帧驱动。这是该片分镜选择的布局，不代表已有录屏都该使用相同的 HUD 或底部导航。已有视频可借用 `video-bilingual-degap-navigation` 的转写与剪辑分析，但其固定样式需要由具体成片排版替换。
5. 渲染后 `ffprobe` 核对 1080×1920 / 30 fps / 84.373 秒 / H.264 + AAC 48 kHz 立体声；完整解码通过；9 张关键帧拼联系表逐镜检查层级与安全区。
6. 均值 −19.3 dB 偏小，用 `-c:v copy -af "volume=3dB"` 抬到 −16.4 dB、峰值 −1.3 dB，视频流不重编码。
7. 交付 MP4 + 双语 SRT + `timeline.json` + `manifest.json` + `README.md`（源脚本、音色、规格、重渲命令、SHA-256）。

这一轮真正的成本都在分镜之前：脚本定稿后，配音、时间线、字幕、动画都是机械转译；反而是"进度条位置""模块名是否和镜内小标题重复""四张卡片宽 208 还是 209"这类细节花掉了大部分返工时间。这些细节本可以在分镜阶段用一行字定掉。

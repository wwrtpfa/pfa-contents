# Remotion 剪辑与动效合成

本参考同时适用于已有录屏/口播和从脚本生成的视频。时间线应包含成片时长、剪辑点、源时间到成片时间的映射、双语字幕、章节和动效事件。画面尺寸由素材和发布需求决定，不把 `1080×1920`、固定 HUD 或固定字幕坐标当成所有项目的默认值。

## 已有视频：保持音画同步

1. 先从源视频生成剪辑计划，人工检查每个被删区间的语音、呼吸和画面连续性。把同一组剪辑点同时用于视频和原声，输出一份剪后底片。
2. 将已校对的字幕、章节边界及动效事件从源时间映射到剪后时间。切掉的区间不得留悬空字幕；被切开的句子需重新检查出入点。需要二次调整样式时复用同一剪辑计划，避免悄悄改变剪辑节奏。
3. 在 Remotion 中以剪后底片为底层，外扩画布或使用现有留白加入进度与信息层。不要为了加顶栏缩小或裁掉 UI 细节；若尺寸必须改变，先用关键帧确认文字可读。
4. 已有可用人声时只使用底片音轨。动效音效若确有必要，要控制音量，不盖过讲话；不要让视频组件和独立音轨重复播放同一份声音。

本次录屏的**参考实现，不是通用固定尺寸**：源视频 `3456×2160 / 60 fps`，剪后成片约 `46.8 s`；顶部外扩 `112 px`，画布 `3456×2272`。进度线画在外扩区域，原录屏从 `y=112` 起完整显示。黄色中文字幕约 `94 px`、英文约 `62 px`，在画面下部居中，暗色描边，无底板。其他素材按可读性和参考图重新布局。

## 动效按内容放置

为每个动效记下：对应哪句话、入场/变化/退场时间、想说明的关系、占用区域、会避开的原画面元素。优先用原画面中的证据做轻量增强，例如局部框选、指向箭头、阶段递进、前后对比、局部放大；需要抽象说明时制作相应的动效插图。只有原画面不能清楚说明概念时，才插入独立信息镜头。

顶栏可以承载进度和简短章节，但它不是所有动效的容器。若录屏上部已有密集 UI，把动效放在留白或短暂说明镜头；若下部有人脸或字幕，也不要往下部硬塞。动效应跟随讲述进入，在读完后退出，避免长时间悬挂。素材和效果从实际内容推导，不预设每条视频都用同一组图标。

## 字幕与顶部进度

- 字幕跟随剪后人声，不跟随原始时间码。中文一行、英文一行优先；长句按语义分段，确保手机预览时能读完。默认黄色、暗描边、透明背景；只有用户参考图另有要求时更改。
- 字幕位置先依据参考图，再依据被遮挡的内容调整；选择画面下部的可读区域，并留出平台 UI 安全区。检查开头、中段、底色最亮的一帧和动效同时出现的一帧。
- 进度线使用剪后总帧数计算 `frame / (durationInFrames - 1)`，首帧为 0，末帧接近 100%。轨道可半透明，整条线必须留在外扩顶栏，不压原视频顶部像素。章节文字和动效不应盖住线条。
- 用户已提供参考图时，用同一时点出对比截图；先确认位置、字号、底色和进度是否符合，再渲染整片。

## 从脚本生成

分镜文本和实测旁白时长生成同一份时间线。逐镜素材、音频和动效用 `<Sequence>` 对齐；字幕和进度在外层按全局帧绘制，避免跨镜淡出时闪烁。若有独立音频，核对片尾没有重叠或丢失。可参考 [shot-list-template.md](shot-list-template.md) 的时间线字段，字段可按项目增减。

## 验收

先用 `remotion still` 导出开头、章节切换、信息最密集和片尾的帧，再渲染 MP4。每个动效在最终成片里至少检查入场前、变化中和退场后的画面。用 `scripts/qa_video.sh` 做规格、解码、响度、联系表和校验值检查；机器检查之外，逐个试听剪辑点并观看动效进出。出现字幕越界、遮住 UI、突然黑帧或吞字时，修复后重渲受影响版本。

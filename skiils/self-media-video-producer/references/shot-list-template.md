# 分镜与时间线模板

从脚本生成时使用逐镜模板；已有口播或录屏时使用后面的素材标注模板。两条路径都要写清声音来源、字幕安全区、进度条位置和动效占用区域。

```markdown
- 观众：
- 平台 / 画幅 / 目标时长：
- 看完能做的一件事（只能一件）：
- 声音来源：原片人声 / 已有旁白 / 待生成旁白
- 画面中不能遮挡的区域：
- 字幕与进度条参考图或指定位置：
```

## 每镜块

```markdown
### 镜 03 · 5 格脚本板

- 结论：先排内容，再谈动效（观众这一镜只记这一句）
- 旁白（逐字）：
  很多人一上来就找模板。先把内容排成五格：
  哪一句是钩子，哪一句给结论，哪一句放证据，
  哪一句做转折，哪一句收尾。
- 主体动作：播放头从上到下依次点亮 5 行（同一时间只有一个元素在动）
- 位置：中部演示区；标题在 y≈300，板在 y≈420–1180，底部留字幕区
- 时点：旁白第 1 句末尾出现板；第 2–4 句逐行点亮；第 5 句箭头扫到底
- 层级：主标题 > 5 行卡片 > 行内小字（行内字比卡片标题小 40%）
- 形式：静态板 + 逐行点亮 + 一个箭头
- 屏幕文字（只写会出现在画面上的字）：
  钩子 / 结论 / 证据 / 转折 / 收尾；角标「5 格脚本板」
- 字幕：中英各一行，跟随旁白，分行不跨动作
- 素材：无外部素材，纯排版
```

尤其容易漏的是「时点」：先写"第几句"，拿到实测音频时长后再回填秒数。已有原声则直接标注源时间，并在去气口后映射到成片时间。

## 已有视频：素材标注块

对需要剪辑或加动效的片段记录以下信息，不必强行拆成固定数量的镜头：

```markdown
### 片段 · 提示词变成原型

- 源时间 / 成片时间：18.3–23.5 s / 待剪辑计划回填
- 原声要点与校对文本：我让它以产品体验官的角度看网站……
- 原画面关键区域：右侧原型、左下人物画中画；不要遮挡
- 剪辑：删掉 19.2 s 附近的明显停顿；保留“产品体验官”句首
- 字幕：黄色中英两行、下部居中、无黑底；本片按参考图调整
- 进度：原视频之外的外扩顶栏，按成片时间推进
- 动效：说到“重新设计”时高亮新原型，约 0.4 s 入场；放在右侧留白
- 验收帧：动效出现、字幕最长、章节切换各抽一帧
```

这些只是字段示例，内容必须来自实际视频和参考图。动效位置由原画面排版决定，不能机械套用示例坐标。

## 节奏规则

- 镜头时长由讲述和阅读量决定。已有录屏不为符合固定秒数而打断连贯操作。
- 章节跟随语义变化，不为凑章节数量而制造切换。
- 转场只在内容关系需要时使用，动效进出要留足阅读时间。

## 时间线换算

以下换算只适用于按段合成旁白的脚本视频；已有视频的成片时长由保留区间之和决定，不要再叠加旁白或固定镜间隙。

```text
gap  = 0.34 s
tail = 1.0 s
total_seconds   = Σ speech + gap × (n − 1) + tail
total_frames    = round(total_seconds × fps)
scene_frames[i] = round((speech[i] + gap) × fps)
```

旁白句内不要留长静音，否则字幕无法与动作对齐。合成后先做首尾静音裁剪再归一化，再切段测时长。

## 机器可读时间线

脚本定稿后生成 `timeline.json`。已有视频另需记录 `cuts` 或保留区间，以及源时间到成片时间的映射：

```json
{
  "fps": 30,
  "width": 1080,
  "height": 1920,
  "duration": 84.376,
  "durationInFrames": 2531,
  "gaps": { "between": 0.34, "tail": 1.0 },
  "scenes": [
    {
      "id": "03-content",
      "module": "01 · 内容先排好",
      "step": "01 / 03",
      "accent": "green",
      "audio": "audio/03-content.wav",
      "audioDuration": 7.853,
      "start": 16.93,
      "duration": 8.193,
      "subtitles": [
        { "start": 0.0, "end": 3.1, "zh": "很多人一上来就找模板", "en": "Most people reach for a template first" }
      ]
    }
  ]
}
```

上例字幕的 `start` / `end` 是**镜内相对秒**，渲染时加上 `scene.start` 就是全局时间。已有视频的字幕应直接使用剪后的全局秒数，避免重复映射。

- [ ] 每镜或片段都标明原画面中不能遮挡的区域、字幕区和进度区
- [ ] 屏幕文字在目标尺寸可读，未与已有 UI 或字幕重叠
- [ ] 有原声时已确认不生成重复配音；新旁白念一遍，语速自然
- [ ] 需要封面时，封面钩子与视频实际内容相符
